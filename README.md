# Ember · Web-Tisch

Dieser Branch ist der spielbare Tisch aus dem Preview. `main` bleibt der lokale Server.

Drei Eingänge, auch nach dem Neuladen:

- **Die Glut zünden** — Spielleitung, Fear, Bögen, Duality, Karte, Reihenfolge
- **Ans Feuer setzen** — eigener Sitz, PIN vom Bogen
- **Unter die Schwelle** — Solo, vier Räume, einmal gelegt

Der Stand liegt in diesem Browser. Kein LAN, kein Tunnel, keine Pixelstube.

```bash
npm install
npm run dev
```
